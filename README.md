
# Game Boy Emulator

Cycle-accurate-ish Game Boy (DMG) emulator in C++ with CPU, memory, and PPU subsystems.

* Passes all CPU blargg tests
* Passes dmg-acid2 test for ppu
* Tetris and Dr.Mario run perfectly
